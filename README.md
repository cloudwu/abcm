# 智能 ABC·改

给 Rime 用的智能 ABC 方案。

这个项目受 https://github.com/andelf/remi-znabc 启发而开始。使用了其中的智能 ABC 笔划表，代码部分则从头手工开发。

## 安装

1. 安装 [RIME](https://rime.im/)
2. 打开 RIME 的用户文件夹
3. 将本项目的 rime 文件夹中所有文件复制进去
4. 在 RIME 中重新设定方案，应该能看到本方案“智能 ABC·改”

## 思路

尽可能的保留 RIME 默认机制，方便用户在本方案基础上继续调整。用合适 RIME 的机制添加智能 ABC 中的特性：包括并不限于：数字笔划码、以词取字、i 模式快速输入数字等。

不导入原智能 ABC 词库，不额外支持用户自定义词（RIME 自带）。手感仅做少量微调以适应原智能 ABC 用户使用习惯，但不追求完全一致。

## 已完成

* 笔划码已整合。这是 ABC 输入法中最关键的部分，可以用 1-8 跟在拼音（全拼或声母）后面，减少单字重码。因为数字用于编码，所以 ABC 的交互和传统拼音方案略有不同。输入编码后，第一次空格键才弹出被选单，这个时候进入选择模式，方可用数字键选择，或再用一次空格键确认默认项。但也可以继续输入后续，会将之前的默认项上屏。
* 可用 [] 以词选字。即输入一个已有词后，用 [ 表示需要这个词的首字，或用 ] 表示取其末字。避免先输入一个词再删去不需要的字。
* 用 i/I 可以快速输入数字及量词。
* 当尝试输入一个词、而词库中没有时，如果逐个选字完成并上屏，该词会被自动记入用户词库。输入法默认会尽量做最长匹配，不满意其匹配时，按 Backspace 进入单字选择模式。

## 特色功能

* 在中文状态下，如果输入明显不能构成中文编码的内容，自动以原文形式上屏，并自动转为 Ascii 模式，再次输入汉字需要手动切换。例如，如果输入大小写混合的单词、带下划线的单词，一律认为在编写代码。另外，内置了一些编程常见关键词，一旦发现输入它们也会自动切到 Ascii Mode ，这些关键词配置在源码文件中，目前只配有 Lua 关键字。
* u 开头的自造词输入取消，取而代之的是 u 接 1-8 数字键，用纯笔划码查字。
* v 开头在原版 ABC 中可以临时输入一个英文单词，或接数字选择特殊符号。这里只保留了临时输入英文的功能，并进一步加强：v 键后的任何非控制键都按原始 ascii 字符保留，包括空格，直到按回车全部上屏。
