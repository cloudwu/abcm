# 智能 ABC·改

给 Rime 用的智能 ABC 方案。

这个项目受 https://github.com/andelf/remi-znabc 启发而开始，使用了其中的智能 ABC 笔划表，其余部分从头手工开发。

由于我第一次给 RIME 开发方案，对 RIME API 很不熟悉，所以进度很慢。目前只完成了相当初步的工作，这个方案仅能运行，输入手感还需要很多调整工作。

## 安装

1. 安装 [RIME](https://rime.im/)
2. 打开 RIME 的用户文件夹
3. 将本项目的 rime 文件夹中所有文件复制进去
4. 在 RIME 中重新设定方案，应该能看到本方案“智能 ABC·改”

## 思路

尽可能的保留 RIME 默认机制，方便用户在本方案基础上继续调整。用合适 RIME 的机制添加智能 ABC 中的特性：数字笔划码减少同音重码、以词取字、i 模式快速输入数字等。

不导入原智能 ABC 词库，不额外支持用户自定义词（RIME 自带）。输入手感做少量微调以适应原智能 ABC 大致手感，但不追求完全一致。

## 开发进度

目前只完成了笔划码嵌入和 i 前缀的快速数字输入。

现最大问题是无法用数字选同码词（但可以用方向键选择），这是因为智能 ABC 本身需要用数字编码，使用 RIME 默认配置产生了冲突。需要继续调整确认和上屏流程（开发中）。
